5.1 Settings reference

All of these are in Preferences → Sources → Media Intake. Hover over any option to see its tooltip.

SettingDefaultWhat it does
Incoming Folders (+ / −, Choose…)noneThe folders M3 looks in. Loose files are wrapped in a folder of their own; folders holding media (up to three levels down) become releases.
Scan Now—Looks in the Incoming Folders immediately and adds what it finds, even when watching is off, without waiting for files to settle. TV episodes go to the TV Shows Queue.
Reset Scan…—Forgets which files the scan has already taken in, then scans again. Use it when something sitting in an Incoming Folder is not being picked up, for example after you removed its row from the Queue. Anything already in a Queue is not duplicated.
Automatically watch these folders for new filesoffWatches the folders and also re-checks every 20 seconds. A new item is added once its files have stopped changing for about 10 seconds.
Automatically approve high-confidence naming matchesoffApproves the suggested name without a click when the online title matches exactly.
Rename the source folder after merging, when a correct name is foundoffAfter a manual Queue merge, renames the download folder to a correct release name found nearby (a cover image, the folder name, or a well-named video). Never overwrites an existing folder.
Automatically merge multi-file releases with a clear sequenceoffWhen every part carries a sequence number and the parts are compatible, merges after about a second instead of stopping at Merge Review. Opening the row in that second cancels it.
Remove empty folders automaticallyoffAfter each Queue run and each editor save, moves empty folders inside the Incoming and Ready folders to the Trash and logs them. Folders touched in the last two minutes are left alone. The same cleanup can be run by hand with Window → Clean Up Empty Folders….
Clean up processed filesoffAfter a release is moved into Ready for Media Library, moves the original files it was made from (the parts that were merged, or the unconverted source when the Queue converted a file) to the Trash and logs them. The finished file is never touched. This applies to Queue runs only; it does not apply to a file you tag with Edit and Save (see 5.4).
Remove finished items from the Queue automaticallyoffWhen a Queue run finishes, the rows with a checkmark are taken off the list. Only the rows are removed, never files. Failed rows and rows still waiting for you stay.
Run the Movies and TV Shows queues at the same timeoffOff: the two queues take turns, one file at a time, which is kinder to a single disk. On: each queue works by itself, so two files can be processed at once. Turn it on only if your files are on fast drives such as SSDs.
Ready for Media LibrarynoneNow set on the Media Locations tab (see 5.5), where it is the staging folder: finished files wait there for you to check them.
Automatically Add to Apple TV FoldersNow on the Media Locations tab (see 5.5), where it is the default destination.
