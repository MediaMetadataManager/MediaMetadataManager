9. Troubleshooting

ProblemCause and fix
A download is not picked upIt is still growing (wait or click Scan Now); its folder holds a .part file; the folder is not listed under Incoming Folders; or its path is inside the Ready folder.
A new file with an old name is ignoredUpdate to a build that forgets finished paths. In older builds the name had been remembered.
The folder name came out as [] ()The file was saved with no title tagged. Current builds leave such files alone; run Search Metadata before saving.
Naming Review finds no matchThe title may include a performer or subtitle the provider does not use. Edit the name, or use Search All Providers….
Merge failedOpen the row and read the reason. Parts must share codecs, track layout and picture size.
Merge is greyed outSelect two or more items that have not been processed yet.
The toolbar is missing a buttonRight-click the toolbar → Customize Toolbar… and drag it in.
Nothing happens on StartThe Queue is empty of items that are Ready. Releases waiting for naming, a metadata decision or a merge order are not run until you finish those steps.
