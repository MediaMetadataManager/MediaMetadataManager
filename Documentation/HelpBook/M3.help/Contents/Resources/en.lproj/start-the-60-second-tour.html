The 60-second tour

M3 has four places you will use:

WindowWhat it is for
Queue: Movies tabThe home of your work. Every file or folder waiting for naming, tagging or merging is one row.
Queue: TV Shows tabThe same list on its own tab, kept separate so TV episodes do not mix with movies.
EditorOpens one file so you can search for metadata, edit tags, change artwork and save.
SettingsWhere you choose metadata sources, naming rules and the Media Intake options.

Work flows in one direction: Incoming Folder → Queue → (review where needed) → Ready for Media Library. Nothing is moved into your final library without passing through the folder you chose.
