If something looks wrong

You seeTry this
A download never appears in the QueueClick Scan Now. Check the folder is listed under Incoming Folders and that the download has finished (files ending in .part or .crdownload are skipped).
A row says RejectedYou rejected its name. Double-click the row to review it again.
A merge failedThe row shows the reason in plain language, for example parts with different video formats. Reopen the row to change the selection.
The match is wrongIn the Metadata Review sheet or the editor, search again or choose another result. Search All Providers… in the Naming Review sheet shows one result from every enabled source.
You deleted something by mistakeItems removed by the Queue’s cleanup options go to the macOS Trash and are listed in log files in ~/Library/Application Support/M3/. A single file saved from the editor is changed in place and moved to Ready, with no original kept, so restore it from your own backup.
